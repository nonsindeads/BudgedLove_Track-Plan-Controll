# BudgetLove Wiki

BudgetLove is a self-hosted household finance app for tracking, planning, open cases, planned payments, receipts, split bookings, cloud-backed SQLite storage, and AI-assisted workflows.

This wiki mirrors the maintained repository documentation. The repository docs remain the canonical source for review and pull requests.
